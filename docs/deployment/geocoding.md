# Geocoding and map tiles

Select a company-approved HTTPS reverse-geocoding service and confirm its usage policy for employee coordinates. Configure its endpoint, user agent and required API key on the API. Test unavailable and rate-limited responses. The coordinate evidence remains available when the provider cannot resolve an address.

Set the approved Vercel tile URL and attribution using the admin environment template. Review privacy, tile capacity and attribution terms before production. The map displays recorded points.
