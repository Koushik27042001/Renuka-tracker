# MongoDB Atlas

Create a dedicated production database and a service user restricted to that database. Keep database administration and backup privileges with an operator account. Use TLS SRV with hostname verification. Restrict access to approved Render egress or private networking and verify the egress addresses for the chosen service.

Enable Atlas snapshots for a supported tier. Run the release index command through a controlled service deployment. Restore to an isolated database and confirm employee uniqueness, active shift and visit idempotency indexes before opening traffic.
