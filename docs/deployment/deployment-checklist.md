# Deployment checklist

- [ ] Create isolated staging and production resources and approve regions.
- [ ] Provision scoped credentials and approved network access.
- [ ] Deploy API with indexes and verify readiness.
- [ ] Deploy the dashboard and verify refresh cookie and CORS behavior.
- [ ] Exercise the evidence workflow in staging.
- [ ] Confirm approved hosting, signing, release checksums, and physical device checks.
- [ ] Complete [the production launch checklist](../production-launch-checklist.md).
